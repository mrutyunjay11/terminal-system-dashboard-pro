STEP 1 — INTRODUCTION AND STARTUP  [0:00 — 0:25]
--------------------------------------------------------------------------------

Before recording:
- Open your terminal.
- Make it wide enough so the dashboard panels are not cut off.
- Navigate to the project folder and activate the virtual environment.

Action:
  Type: clear
  Then type: python project.py

Speaking (while the ASCII logo and "Initializing..." message appear):

  "Hi, my name is Mrutyunjay Joshi, and this is my CS50P final project.
  It is called Terminal System Dashboard Pro.
  On startup, it prompts for sudo to enable low-level hardware monitoring.
  It collects CPU, memory, disk, network, battery, and process data,
  and displays it in a live dashboard built with the Rich library."


STEP 2 — WALK THROUGH THE DASHBOARD PANELS  [0:25 — 1:05]
--------------------------------------------------------------------------------

Action:
  The dashboard should now be running on screen.
  Point at or gesture toward each panel as you describe it.

Speaking:

  "The dashboard is split into several panels.

  At the top is a header showing the OS, uptime, current user, and Python version.

  On the left side, the CPU panel shows the processor model, architecture,
  and core counts (including P-core and E-core splits on Apple Silicon).
  It also tracks GPU and Neural Engine cores, overall usage, individual P/E
  core progress bars, and real-time CPU and GPU power consumption in Watts.

  Below that, the Memory and Storage panel shows RAM and swap usage with
  progress bars. It also lists disk partitions with used and free space,
  and shows live disk read and write speeds.

  Under that is the Power and Battery panel. Beyond charge percentage,
  it displays detailed diagnostics: current and virtual temperature, cycle count,
  wear level, nominal and design capacities, live voltage, and current in mA.

  On the right, the Network panel shows the hostname, local IP,
  whether the machine is online, and current upload and download speeds.

  Below it, the Processes panel shows the top CPU-consuming and
  top memory-consuming processes side by side."


STEP 3 — DEMONSTRATE KEYBOARD SHORTCUTS  [1:05 — 1:45]
--------------------------------------------------------------------------------

Action:
  Press the T key a few times.

Speaking:

  "Pressing T cycles through the five built-in themes.
  There is dark, light, cyberpunk, matrix, and ocean.
  The colors update immediately."

Action:
  Press T until you get back to a theme you like.

Action:
  Press the R key.

Speaking:

  "Pressing R forces an immediate data refresh."

Action:
  Press the E key.

Speaking:

  "Pressing E exports a snapshot of the current system state.
  The file is saved to the exports folder with a timestamped filename.
  You can see the confirmation in the footer."

Action:
  Press the S key.

Speaking:

  "Pressing S starts an internet speedtest in the background.
  It runs on a separate thread so the dashboard stays responsive.
  When it finishes, the results appear in the network panel."

Action:
  Wait a few seconds for the speedtest status to appear, then continue.
  If it takes too long, move on — you can mention it is still running.

Action:
  Press Q to quit the dashboard.

Speaking:

  "Pressing Q exits the dashboard cleanly."


STEP 4 — DEMONSTRATE CLI OPTIONS  [1:45 — 2:10]
--------------------------------------------------------------------------------

Action:
  Type: python project.py --once

Speaking:

  "The --once flag prints a quick system summary to the terminal and exits.
  It shows the OS, CPU model, load, RAM usage, and uptime."

Action:
  Type: python project.py --export json

Speaking:

  "The --export flag generates a report file and exits immediately.
  It supports json, csv, and txt formats.
  The file is saved to the exports folder."
